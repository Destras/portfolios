## States and edge cases
- Text length: EN is the only rendered language; the intro wraps inside the column. Row labels are short.
- 320 px: rows keep label · path · → on one line; the path may wrap (`overflow-wrap: anywhere`) before the label does. Long typed paths in the path line wrap with `overflow-wrap: anywhere` (as the wireframe).
- 200% zoom: "404" uses a clamp in rem, so it scales with the user's font size.
- Current nav link: none (the 404 isn't a section).
- External links: none in the body (footer handles its own).
- Anchor / reduced motion: no anchors; the → appears with no transition (§3: no transitions in the MVP).
- Dark mode: tokens only; check row hover surface and muted "404" in both modes.
- Missing data: no JS → the path line stays `hidden`, no gap left.
- **Language switch:** `ES` → `/es/` (D-404-12). On a direct visit to `/404.html` the path line is redundant, so the script skips it there.
- **Encoded paths:** `/es/año/` arrives as `/es/a%C3%B1o/`; the script shows it decoded, and a malformed escape (`/%E0%A4%A/`) falls back to the raw path instead of throwing.
