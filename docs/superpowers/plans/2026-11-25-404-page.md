# 404 Page Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build one English-only 404 page (`src/pages/404.astro` → `dist/404.html`), shown for every missing URL, from the wireframe `design/404page.html`: a decorative "404", an h1, an "I couldn't find {path}" line, an intro, and three link rows.

**Architecture:** `404.astro` writes its own HTML shell (`<html lang="en">`, a `<head>` copied from `Layout.astro` without canonical or hreflang) because `Layout` reads the language from the URL (always `es` here) and must not be touched (D-404-9). It reuses `SkipLink`, `SiteHeader` and `SiteFooter` with `locale="en"`. The body is `NotFoundPage.astro`, which uses a new `LinkRows.astro` component. A pure `displayPath()` function, unit-tested with `node --test`, drives a small processed `<script>` that fills the path line.

**Tech Stack:** Astro 7 (static, no adapter), TypeScript, scoped `<style>` with design tokens, Node 26 built-in test runner (native TS type stripping). The other checks are `npm run check`, `npm run build`, and greps on `dist/`.

**Spec:** `design/pages/404.md` (approved by the owner on 2026-11-25, decisions D-404-1…D-404-15). Visual reference: `design/404page.html` (desktop 1440 and mobile 375, day and night). The audit table in the spec maps every wireframe value to a token. Use it and never copy the wireframe's values.

**Astro docs relied on:**
- https://docs.astro.build/en/basics/astro-pages/#custom-404-error-page (`src/pages/404.astro` builds to `404.html`)
- https://docs.astro.build/en/reference/api-reference/#currentlocale (falls back to `defaultLocale` with no locale prefix, which is why the page has its own shell)
- https://docs.astro.build/en/guides/client-side-scripts/#script-processing (a bare `<script>` is bundled as a TS module and can import `displayPath`)

## Review Focus

1. **A missing `/es/…` URL** gets the English page with `<html lang="en">`, and the header and footer in English: no Spanish chrome leaks in from `Astro.currentLocale`. Checked in Task 4, Step 4.
2. **Encoded and malformed paths:** `/es/a%C3%B1o/` shows `/es/año/`. `/%E0%A4%A/` shows the raw path and doesn't throw. `<script>` in the path shows as text and isn't executed. Tested in Task 5, Steps 1 and 5.
3. **Long typed paths at 320 px:** a 200-character path wraps inside the column (`overflow-wrap: anywhere`), with no horizontal scroll. Manual check in Task 6.
4. **Keyboard:** each row shows the global `:focus-visible` outline and the `→`, same as on hover. Manual check in Task 6.
5. **No JS:** the path line stays `hidden` and leaves no gap between the h1 and the intro. Checked in Task 4, Step 4 (`hidden` in `dist/404.html`).
